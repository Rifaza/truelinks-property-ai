# TrueLinks Property AI

A full-stack AI-assisted property management service built as part of the TrueLinks.AI SDE-Platform & Products technical exercise.

## Planned Features

- Lease document extraction
- Evidence-backed structured lease records
- Lease validation against owner rules
- Unit matching and occupancy tracking
- Property issue detection from photos
- Draft work-order generation
- Human-in-the-loop review

## Tech Stack

- React + TypeScript
- Python + FastAPI
- PostgreSQL
- SQLAlchemy
- Pytest

Work in progress.
